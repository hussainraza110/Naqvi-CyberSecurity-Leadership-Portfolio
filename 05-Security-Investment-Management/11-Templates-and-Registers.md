# Templates and Registers

## Investment intake register
| Field | Description |
|---|---|
| Investment ID | Unique identifier |
| Title / sponsor | Proposal name and accountable sponsor |
| Risk / obligation | Scenario or formal driver |
| Affected service / assets | Business scope |
| Mandatory flag / due date | Obligation tracking |
| Options / recommendation | Alternatives and rationale |
| Estimate / confidence | Cost range and estimate maturity |
| Dependencies / capacity | Prerequisites and delivery constraints |
| Target outcome | Baseline, target, measure, owner |
| Decision status | Submitted, assessed, approved, deferred, rejected |
| Review date | Next checkpoint |

## Change control
Changes to approved scope, cost, schedule, risk outcome, or operating model require impact assessment and delegated approval. Preserve the original baseline and record the change date and rationale.
