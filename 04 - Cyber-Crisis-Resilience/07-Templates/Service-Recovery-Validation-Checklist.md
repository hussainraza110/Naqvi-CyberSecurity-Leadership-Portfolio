# Critical Service Recovery Validation Checklist

- [ ] Incident scope and trust boundaries assessed
- [ ] Recovery environment isolated from compromised paths
- [ ] Recovery source integrity verified
- [ ] Identity and privileged access trusted/tested
- [ ] Required controls and monitoring active
- [ ] Data integrity and reconciliation checks completed
- [ ] Technical functional tests passed
- [ ] Business owner validates fitness for use
- [ ] Customer/backlog handling agreed
- [ ] Residual risks and heightened monitoring documented
- [ ] Recovery approval and timestamp recorded
